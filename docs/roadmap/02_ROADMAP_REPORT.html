⚙️ Considerações Técnicas & Limitações

📦 Escalabilidade

Desafio: 2100+ links pode crescer exponencialmente

Solução: Caching em Redis, indices de banco otimizados, async processing

🔄 Sincronização

Desafio: Manter sincronizado com múltiplas fontes (Odoo, SAP, GitHub)

Solução: Webhooks + Event-driven architecture + retry logic

💵 Custos API

Desafio: Claude API pode ficar caro com muitos chats

Solução: Rate limiting, quotas por usuário, cache de respostas

🌍 Dados Sensíveis

Desafio: Links podem conter info de SAP/HR confidencial

Solução: Criptografia em repouso, RBAC granular, audit log
