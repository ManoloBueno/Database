1️⃣ Arquitetura Geral de Integrações

Visão Geral

O Banco de Links usa um padrão event-driven com webhooks para integrar com sistemas externos. Cada integração funciona de forma assíncrona para não bloquear a API principal.

┌─────────────────────────────────────────────────────┐ │ BANCO DE LINKS (FastAPI) │ │ ┌──────────────────────────────────────────────┐ │ │ │ API Core │ │ │ │ ├─ POST /links (criar) │ │ │ │ ├─ PUT /links/{id} (atualizar) │ │ │ │ └─ DELETE /links/{id} (deletar) │ │ │ └──────────────────────────────────────────────┘ │ │ ↓ │ │ ┌──────────────────────────────────────────────┐ │ │ │ Event Bus (Redis/RabbitMQ) │ │ │ │ Fila de eventos para processamento async │ │ │ └──────────────────────────────────────────────┘ │ │ ↙ ↓ ↘ ↗ │ └─────────────────────────────────────────────────────┘ ↓ ↓ ↓ ↓ ┌───────────────────────────────────────┐ │ Odoo CRM │ SAP-GUI │ Slack │ │ (webhook) │ (API) │ (webhook)│ └───────────────────────────────────────┘

Componentes Principais

Componente Responsabilidade Tecnologia
Integration Worker Processa eventos e sincroniza com sistemas externos Celery + Redis
Event Bus Fila de mensagens para comunicação assíncrona Redis Pub/Sub ou RabbitMQ
API Gateway Autentica e roteia requests para integrações FastAPI + OAuth2
Webhook Receiver Recebe eventos de sistemas externos FastAPI WebSocket

2️⃣ Integração Odoo CRM

Objetivo

Sincronizar links com pipeline de vendas do Odoo. Quando um link é criado/atualizado, cria ou atualiza uma Lead/Opportunity correspondente no Odoo.

Fluxo de Dados

Banco de Links Odoo CRM ↓ ↓ 1. Usuário cria link ↓ 2. API valida e salva no DB ↓ 3. Emite evento "link.created" ↓ 4. Event Bus recebe ↓ 5. Worker assíncrono processa ↓ 6. Chama Odoo RPC API ↓ 7. Cria Lead/Opportunity ↓ 8. Sincroniza tags como "tags" do Odoo ↓ 9. Persiste Odoo ID no Banco de Links ↓ 10. Usuario vê "Synced ✓" no UI

Configuração Odoo

Pré-requisitos:

✓ Odoo 14+ com módulo CRM ativado
✓ Usuário XML-RPC com permissões de criar leads
✓ Acesso SSH para configurar credenciais

Environment Variables

# .env ODOO_URL=https://odoo.empresa.com.br ODOO_DATABASE=producao ODOO_USERNAME=banco_links_user ODOO_PASSWORD=senha_segura_aqui ODOO_SYNC_ENABLED=true ODOO_DEFAULT_TEAM_ID=1 # Equipe de vendas padrão

Cliente Odoo (app/integrations/odoo/client.py)

import xmlrpc.client import os from typing import Dict, List class OdooClient: """Cliente para Odoo RPC XML-RPC""" def __init__(self): self.url = os.getenv("ODOO_URL") self.db = os.getenv("ODOO_DATABASE") self.user = os.getenv("ODOO_USERNAME") self.pwd = os.getenv("ODOO_PASSWORD") self.uid = None self._authenticate() def _authenticate(self): """Autentica com Odoo""" common = xmlrpc.client.ServerProxy( f"{self.url}/xmlrpc/2/common" ) self.uid = common.authenticate( self.db, self.user, self.pwd, {} ) if not self.uid: raise Exception("Odoo auth failed") def create_lead(self, data: Dict) → int: """Cria uma Lead no Odoo""" models = xmlrpc.client.ServerProxy( f"{self.url}/xmlrpc/2/object" ) lead_id = models.execute_kw( self.db, self.uid, self.pwd, 'crm.lead', 'create', [data] ) return lead_id def update_lead(self, lead_id: int, data: Dict): """Atualiza uma Lead no Odoo""" models = xmlrpc.client.ServerProxy( f"{self.url}/xmlrpc/2/object" ) models.execute_kw( self.db, self.uid, self.pwd, 'crm.lead', 'write', [[lead_id], data] )

Modelo de Sincronização (app/integrations/odoo/models.py)

from typing import Dict class LinkToOdooMapper: """Mapeia Link do Banco para Lead no Odoo""" @staticmethod def link_to_lead(link: Dict) → Dict: """Converte Link para Lead data""" return { "name": link["titulo"], "description": link["resumo"], "tag_ids": _get_or_create_tags(link["tags"]), "team_id": os.getenv("ODOO_DEFAULT_TEAM_ID"), "website": link["url"], "notes": f"Fonte: {link['plataforma']}\nData: {link['data']}", "email_cc": "banco-links@empresa.com.br", }

Task Celery de Sincronização

from celery import shared_task from app.integrations.odoo.client import OdooClient from app.integrations.odoo.models import LinkToOdooMapper @shared_task(bind=True, max_retries=3) def sync_link_to_odoo(self, link_id: int): """Sincroniza um link para Odoo""" try: # Get link from DB link = db.query(Link).filter(Link.id == link_id).first() if not link: return # Connect to Odoo odoo = OdooClient() lead_data = LinkToOdooMapper.link_to_lead(link.to_dict()) # Create or update lead if link.odoo_lead_id: odoo.update_lead(link.odoo_lead_id, lead_data) else: odoo_id = odoo.create_lead(lead_data) link.odoo_lead_id = odoo_id db.commit() logger.info(f"✓ Synced link {link_id} to Odoo") except Exception as e: logger.error(f"✗ Failed to sync link {link_id}: {e}") # Retry com backoff exponencial self.retry(exc=e, countdown=60 * (2 ** self.request.retries))

3️⃣ Integração SAP-GUI

Objetivo

Enriquecer links com dados de SAP. Quando um link é criado em módulos SAP (MM, FI, HR), puxa dados relevantes automaticamente (tabelas, estruturas, campos específicos).

Fluxo de Dados

Banco de Links SAP-GUI ↓ ↓ 1. Link criado com tag "SAP" ↓ 2. Event emitido ↓ 3. Worker assíncrono ativa ↓ 4. Conecta via RFC/BAPI ↓ 5. Extrai metadados: ├─ Módulo (MM/FI/HR) ├─ Tabelas relacionadas ├─ Estrutura de dados └─ Campos principais ↓ 6. Monta enriquecimento ↓ 7. Salva metadados no Banco ↓ 8. UI mostra "SAP Data ✓"

Configuração SAP

✓ SAP System com RFC habilitado
✓ RFC User com permissões de leitura (PFCG: S_RFC_ADM)
✓ Librfc32.dll (Windows) ou librfc.so (Linux)
✓ nwrfc38 ou pyrfc instalado

Environment Variables

# .env SAP_ASHOST=192.168.1.100 # IP do SAP Application Server SAP_SYSNR=01 # System Number SAP_CLIENT=100 # Client (Mandante) SAP_USER=BANCO_LINKS_USR SAP_PASSWORD=senha_segura SAP_LANG=EN SAP_SYNC_ENABLED=true # RFC Connection RFC_LIB_PATH=/opt/sap/nwrfcsdk/lib

Cliente SAP (app/integrations/sap/client.py)

import pyrfc import os from typing import Dict, List class SAPClient: """Cliente para SAP RFC""" def __init__(self): self.connection_params = { "ashost": os.getenv("SAP_ASHOST"), "sysnr": os.getenv("SAP_SYSNR"), "client": os.getenv("SAP_CLIENT"), "user": os.getenv("SAP_USER"), "passwd": os.getenv("SAP_PASSWORD"), "lang": "EN", } self.conn = None self._connect() def _connect(self): """Conecta ao SAP""" try: self.conn = pyrfc.Connection(**self.connection_params) logger.info("✓ Connected to SAP") except pyrfc.CommunicationError as e: logger.error(f"✗ SAP Connection Error: {e}") raise def get_table_info(self, table_name: str) → Dict: """Retorna info de uma tabela SAP""" try: result = self.conn.call('DD_GET_TABLE', TABLE_NAME=table_name ) return result except Exception as e: logger.error(f"✗ Failed to get table {table_name}: {e}") return None def read_table(self, table_name: str, where: str = "", max_rows: int = 1000) → List[Dict]: """Lê dados de uma tabela SAP""" try: result = self.conn.call('RFC_READ_TABLE', QUERY_TABLE=table_name, ROWCOUNT=max_rows, WHERE=[{"TEXT": where}] if where else [] ) return result.get("DATA", []) except Exception as e: logger.error(f"✗ Failed to read table {table_name}: {e}") return [] def get_bapi_info(self, bapi_name: str) → Dict: """Retorna documentação de um BAPI""" try: result = self.conn.call('BAPI_QUERY_IOBJECT', IOBJECT_NAME=bapi_name, IOBJECT_TYPE='M' ) return result except Exception as e: logger.error(f"✗ Failed to get BAPI {bapi_name}: {e}") return None

Enriquecimento de Links SAP

class SAPEnricher: """Enriquece links com dados SAP""" def __init__(self): self.sap = SAPClient() def enrich_mm_link(self, link: Dict) → Dict: """Enriquece link de MM (Materiais)""" materials = self.sap.read_table( "MARA", where="MTART = 'FERT'", max_rows=100 ) return { **link, "sap_module": "MM", "sap_tables": ["MARA", "MARV", "MARC"], "sap_materials_sample": len(materials), "sap_enriched_at": datetime.utcnow(), } def enrich_fi_link(self, link: Dict) → Dict: """Enriquece link de FI (Financeiro)""" return { **link, "sap_module": "FI", "sap_tables": ["BKPF", "BSEG", "SKB1"], "sap_enriched_at": datetime.utcnow(), }

Task de Sincronização SAP

@shared_task(bind=True, max_retries=2) def enrich_link_with_sap(self, link_id: int, sap_module: str): """Enriquece link com dados SAP""" try: link = db.query(Link).filter(Link.id == link_id).first() if not link: return enricher = SAPEnricher() if sap_module == "MM": enriched = enricher.enrich_mm_link(link.to_dict()) elif sap_module == "FI": enriched = enricher.enrich_fi_link(link.to_dict()) else: return # Save enrichment data link.sap_data = json.dumps(enriched) link.sap_module = sap_module db.commit() logger.info(f"✓ Enriched link {link_id} with SAP data") except Exception as e: logger.error(f"✗ Failed to enrich link {link_id}: {e}") self.retry(exc=e, countdown=120)

⚠️ Limitações SAP
• RFC lento para tabelas muito grandes (use filtros WHERE)
• Conexão requer VPN/firewall configurado
• RFC_READ_TABLE tem limite de 1000 linhas (ajustável com ROWCOUNT)
• Dados sensíveis (HR) requerem auditoria LGPD
✓ Vantagens da Integração SAP
• Contexto completo de dados MM/FI/HR em tempo real
• Links automaticamente categorizados por módulo SAP
• Reduz necessidade de copiar dados manualmente
• Rastreabilidade completa de documentação SAP

# app/api/integrations/auth.py from fastapi import APIRouter, Depends, HTTPException from fastapi.security import OAuth2PasswordBearer router = APIRouter(prefix="/api/integrations") oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token") def get_current_user(token: str = Depends(oauth2_scheme)): """Valida token JWT do usuário""" try: payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"]) user_id = payload.get("sub") if not user_id: raise HTTPException(status_code=401) return user_id except jwt.InvalidTokenError: raise HTTPException(status_code=401)

5️⃣ Tratamento de Erros & Retry

Erro Causa Solução
Connection Timeout Odoo/SAP inacessível Retry com exponential backoff (60s, 2m, 5m)
Auth Failed Credenciais inválidas Alertar admin, desabilitar integração
Rate Limit Muitas requisições Colocar na fila com delay maior
Data Sync Conflict Link deletado enquanto sincroniza Log de conflict, rollback na origem
